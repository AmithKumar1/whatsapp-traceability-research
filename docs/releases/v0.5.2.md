# WhatsApp Traceability Research Lab v0.5.2

**Release date:** 2026-10-23  
**Stage:** Alpha research prototype  
**License:** MIT

## What is included

- Signed synthetic evidence manifests with integrity and inventory checks.
- A multi-approver authorization-policy laboratory.
- An offline Merkle inclusion-proof laboratory.
- Synthetic path and tree traceback models, source-only disclosure model, HTS threshold model, and minimal-trust policy model.
- A unified benchmark/comparison harness, JSON Schemas, example reports, reproducibility guides, and a cross-platform CI matrix.
- Release automation that rebuilds and validates distribution assets from the tagged source only after the full CI matrix and packaging job pass.

## Verification

This release is published by the GitHub Actions version-tag workflow after the nine OS/Python test jobs and the distribution-validation job succeed. The release assets include the Python wheel, source distribution, source ZIP, and SHA-256 checksum file.

## Important limitations

- All five protocol adapters are synthetic research models. None is a faithful, interoperable implementation of the cited cryptographic scheme.
- This is an independent project and is not affiliated with, endorsed by, or operated by WhatsApp or Meta.
- There is no live WhatsApp integration, private-chat retrieval, encryption/back-up bypass, or ability to reconstruct forwarding events that were never recorded.
- The restricted canonical-JSON profile is not a complete RFC 8785 implementation; the offline Merkle lab is not a complete transparency log with signed tree heads, consistency proofs, and independent witnesses.
- Results are research prototypes, not security certification, legal advice, or evidence admissibility guarantees.
