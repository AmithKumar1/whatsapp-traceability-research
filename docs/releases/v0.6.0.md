# WhatsApp Traceability Research Lab v0.6.0

**Release date:** 2026-10-24  
**Stage:** Alpha research prototype  
**License:** MIT

## What is included

- **Milestone: Reproducibility Harness & Independent Evaluation**
  - **One-Command Reproduction Harness (`scripts/reproduce_all.py`):** Runs the test suite, generates 11 distinct research artifacts (honest & adversarial path traceback experiments, cross-protocol comparison report, unified synthetic benchmark report, offline Merkle inclusion proof, signed synthetic evidence case, HTS 2025 demo, and Minimal Trust 2026 policy simulation), validates Draft 2020-12 JSON schemas, verifies algorithmic invariants, checks stable semantic consistency, and writes a cryptographic `reproduction-manifest.json` recording environment details, git revision, and SHA-256 hashes.
  - **Epistemic & Algorithmic Research Invariants:** Programmatic invariant checks enforcing candidate-versus-verified origin separation, recipient-view confidentiality (CCS 2019 Theorem 2), protocol forwarder identity binding with server table snapshot invariance, and synthetic non-interoperability verification.
  - **Semantic Baseline Comparison Tool:** Independent regression check separating deterministic protocol properties and qualitative capability matrices from machine-dependent CPU timing jitter.
  - **Researcher Reproducibility Guide (`docs/REPRODUCIBILITY.md`):** Complete walkthrough for clean-room virtual environments, invariant definitions, schema verification, and troubleshooting across Linux, Windows, and macOS.
  - **Regression Test Coverage:** Full suite of 8 reproduction tests in `tests/test_reproduce_all.py`.

- **Milestone: Benchmark Methodology & Dispersion Reporting**
  - **Formal Benchmarking Methodology Specification (`docs/BENCHMARKING.md`):** Formal methodology specification defining linear path workloads ($L \in \{1, 2, 4, 8, 16, 32\}$) and tree workloads ($D \in \{1, 2, 3\}$, $B \in \{2, 3\}$), explicit sample counts, and warmup protocols.
  - **IQR Latency Dispersion Reporting:** Upgraded `src/opentrace/benchmark.py` and `schemas/benchmark-report.schema.json` with Interquartile Range calculations (`construction_ns_iqr`, `trace_ns_iqr`) alongside medians and min/max extremes, capturing non-normal latency dispersion caused by CPU frequency governors, GC pauses, and thread scheduling.
  - **Expanded Hardware Context Collection:** Cross-platform queries capturing `machine`, `processor`, `cpu_count`, and `total_memory_bytes` across Linux, Windows, and macOS.
  - **Standardized Interpretation Boundaries:** Explicit documentation of 5 essential interpretation boundaries (non-interoperability, synthetic-only identities, memory entries vs disk storage, serialized JSON vs wire framing, and topology incomparability).
  - **Benchmark Regression Suite:** 3 new unit tests in `tests/test_benchmark.py` covering IQR dispersion accuracy, hardware disclosure, and schema compliance.

- **Examples & Release Audit Upgrades**
  - Refreshed current-version example reports for v0.6.0: `examples/protocol-comparison-sample-v0.6.0.json`, `examples/protocol-comparison-sample-v0.6.0.md`, `examples/hts2025-demo-sample-v0.6.0.json`, and `examples/minimal-trust2026-demo-sample-v0.6.0.json`.
  - Updated release audit (`scripts/release_audit.py`) and historical documentation in `examples/README.md`.
  - Maintained 123 passing tests with 100% cross-platform coverage across Python 3.11, 3.12, and 3.13 on Ubuntu, Windows, and macOS.

## Verification

This release is published by the GitHub Actions version-tag workflow after the nine OS/Python test matrix jobs and the distribution-validation job succeed. Release assets include the Python wheel, source distribution, source ZIP, and SHA-256 checksum file.

To independently verify this release:
```bash
# 1. Run the reproduction harness
python scripts/reproduce_all.py

# 2. Run the full test suite
python -m pytest -q

# 3. Execute the strict release audit
python scripts/release_audit.py --require-release-date
```

## Important limitations

- The Tyagi et al. (CCS 2019) implementation is an experimental research testbed designed for algorithmic evaluation; it is not a formal cryptographic proof or independent security certification.
- All five protocol adapters are synthetic research models. None is an official or interoperable implementation of live messaging protocols.
- This is an independent research project and is not affiliated with, endorsed by, or operated by WhatsApp or Meta.
- There is no live WhatsApp integration, private-chat retrieval, encryption bypass, or ability to reconstruct forwarding events that were never recorded.
- Results are research prototypes, not security certifications, legal advice, or evidence admissibility guarantees.
