# WhatsApp Traceability Research Lab v0.5.3

**Release date:** 2026-10-24  
**Stage:** Alpha research prototype  
**License:** MIT

## What is included

- Clean-room cryptographic reproduction of the Path Traceback scheme from Tyagi, Miers, and Ristenpart (*ACM CCS 2019* / *ePrint 2019/981*):
  - Canonical symmetric baseline construction using RFC-style domain-separated PRF ($\text{mid} = F(k, m)$), KDF ($K_{\text{enc}} = H(k)$), and stream cipher ($c_{\text{ptr}} = \text{AES-CTR}(K_{\text{enc}}, k_{\text{prev}})$).
  - Recipient-view confidentiality adhering to Theorem 2: predecessor pointer ciphertexts $c_{\text{ptr}}$ are stored strictly in server state and never exposed in recipient message envelopes.
  - Figure 3 missing-lookup termination sampling fresh random predecessor keys $k_{\text{prev}} \leftarrow \{0, 1\}^{256}$.
  - Strict epistemic separation: protocol traversal halts at earliest unverified candidate forwarder; ground-truth certification is separated into evaluation logic.
  - Forwarder identity binding invariant in `forward_message()` (`sender.account_id == received_state.receiver_account` and `sender.device_id == received_state.receiver_device`) failing closed with `ForwarderIdentityMismatchError` prior to key derivation, signing, or table writes.
  - Canonical 4-byte big-endian length-prefixed serialization and NUL byte rejection in `_compute_extension_payload()`.
  - Comprehensive negative tests and full-dictionary server table snapshot invariance tests.
- Bumped build system requirements (`setuptools==84.2.1`, `wheel==0.48.0`) and development dependencies (`cryptography==50.0.2`, `pytest==9.1.1`).
- Signed synthetic evidence manifests, multi-approver authorization lab, offline Merkle inclusion-proof lab, five synthetic research adapters, and a unified benchmark harness.
- Gated release automation validating distributions and cross-platform tests across Ubuntu, Windows, and macOS on Python 3.11, 3.12, and 3.13.

## Verification

This release is published by the GitHub Actions version-tag workflow after the nine OS/Python test jobs and the distribution-validation job succeed. The release assets include the Python wheel, source distribution, source ZIP, and SHA-256 checksum file.

## Important limitations

- The Tyagi et al. (CCS 2019) implementation is an experimental research testbed designed for algorithmic evaluation; it is not a formal cryptographic proof or independent security certification.
- All five protocol adapters are synthetic research models. None is an official or interoperable implementation of live messaging protocols.
- This is an independent research project and is not affiliated with, endorsed by, or operated by WhatsApp or Meta.
- There is no live WhatsApp integration, private-chat retrieval, encryption bypass, or ability to reconstruct forwarding events that were never recorded.
- Results are research prototypes, not security certifications, legal advice, or evidence admissibility guarantees.
