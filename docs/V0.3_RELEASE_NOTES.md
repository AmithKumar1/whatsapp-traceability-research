# WhatsApp Traceability Research Lab v0.3.0 — Research Protocol Baseline

## Added

- `opentrace.protocols.traceback2019` synthetic path-traceback adapter.
- Reference-aligned primitives for the research baseline: SHA3-256-derived truncated hashes/PRFs, HMAC-SHA3-256, and AES-128-ECB block transforms.
- Synthetic server state and path reconstruction.
- Negative tests for wrong content, identity mismatch, duplicate trace addresses, and tag verification.
- `opentrace traceback2019-benchmark` CLI command.
- Research documentation and explicit non-interoperability/reproduction gate.

## Important limitation

This is not yet a formal reproduction of the 2019 implementation. The original Rust project remains the reference target for a later differential-test and benchmark phase.

# WhatsApp Traceability Research Lab v0.3.2 — Unified Synthetic Benchmark

## Added

- Common benchmark schema (`opentrace.benchmark.v1`) for synthetic path and complete-tree workloads.
- `opentrace benchmark` command with path hops, tree depth, branching factors, repeat count, and message byte length controls.
- Construction and trace timing samples plus median/minimum/maximum summaries.
- Ground-truth correctness checks and synthetic nodes/edges disclosed counters.
- Compact JSON trace-size proxy and adapter-state-entry count, both explicitly distinguished from protocol wire/storage costs.
- JSON Schema for benchmark reports, regression tests, CI smoke command, and checked sample report.
- Aggregate tree workload cap to reduce accidental excessive benchmark runs.

## Measurement guardrails

- All IDs and message data are synthetic; no provider or account is queried.
- Measurements apply only to the current Python adapters and machine/runtime environment.
- The adapters are not claimed to be interoperable with the 2019 Rust implementation.
- Complete-tree and linear-path runs are not a controlled cross-topology protocol bake-off.
- No cryptographic security, anonymity, production performance, or legal compliance claim follows from benchmark success.
